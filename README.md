# SegredoDoce

Sistema web desenvolvido para um projeto de TCC.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- PHP
- PostgreSQL
- SendGrid

## Funcionalidades

✔ Cadastro de usuários
✔ Login
✔ Recuperação de senha
✔ Carrinho
✔ Pedidos
✔ Produtos
✔ Painel administrativo
✔ Controle de permissões
✔ Cálculo de frete

## Demonstração

A aplicação pode levar até 30 segundos para iniciar porque está hospedada em um plano gratuito.
